# Demo Walkthrough

## Canonical Persona
`Backend Intern (Node.js)` using the example intro:

`Hi, I'm Riya. I've joined as a Backend Intern working on Node.js.`

## 5-7 Minute Demo Flow

1. Start the app and show the empty onboarding dashboard.
2. Introduce the employee persona in chat.
3. Show the personalized checklist and progress counters.
4. Ask one grounded question such as `How do I set up VPN?`
5. Trigger one agent-driven task such as Node installation or starter ticket open.
6. Show the verification update in the dashboard.
7. Mark the remaining required tasks complete in demo mode.
8. Generate the HR completion report and open the HTML/JSON artifacts.

## Key Talking Points

- Persona-based onboarding path generation
- Grounded RAG with citations
- Checklist visibility and task status tracking
- Resumable onboarding sessions saved locally
- HR-ready completion reporting with confidence score
